Kernel Primitive Mapping Reference

Ready Queue → Lane Waiting Line

Vehicles stacked up at red signals match active processes buffered in ready memory awaiting execution quantum.

CPU Execution → Green Signal Phase

Green phases grant exclusive CPU clock cycles to clear buffered process threads from active lanes.

Context Switch → Yellow Clearance

Yellow signal transitions safely flush remaining lane threads and release shared mutex interlocks before context switching.

Hardware Interrupt → Emergency Vehicle

High-priority emergency interrupts halt normal time-slicing to immediately serve preemptive execution paths.

Supported Scheduling Algorithms

First-Come, First-Served (FCFS)

Non-preemptive algorithm serving processes in strict arrival order.

Shortest Job First (SJF)

Selects threads with the lowest estimated CPU burst times to minimize average waiting metrics.

Round Robin (RR)

Preemptive time-slicing across circular process queues ensuring equal allocation.

Priority + Dynamic Aging

Preemptive min-heap scheduling that dynamically promotes aged threads to prevent starvation.
